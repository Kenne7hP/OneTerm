# OneTerm 功能现状

截至 2026-11-25，版本为 Windows 本地定制版 `2.2.0-local.17`。OneTerm 让用户按项目组织多个命令行工具，在同一个窗口运行任务、查看项目文件、阅读历史对话，并在工具支持时恢复原会话。

## 当前可以使用的功能

| 场景 | 用户可以做什么 | 适用条件与边界 |
| --- | --- | --- |
| 项目与任务 | 添加、固定工作文件夹，按目录启动多个任务。切换任务时终端继续运行，重启后恢复项目、任务列表和选择。 | 关闭终端后仍可保留任务记录。恢复原对话取决于工具是否提供可核对的会话标识。 |
| 任务命名 | 在侧栏用已提交的提示词或已关联的原生标题识别任务，手动命名重要任务。 | 自动更新面向默认编号标题，手动锁定的标题保留。 |
| 终端交互 | 运行系统 Shell 和已检测到的命令行工具，搜索终端内容、选择复制、导出滚动记录，在工具输入框中用 Shift + Enter 换行。 | 导出范围为终端已渲染内容，最多 5,000 行。向上查看历史输出时可保持滚动位置。 |
| 文件与路径 | 浏览项目文件。在终端直接点击本机目录可打开资源管理器，点击文件可在所在目录选中它，Alt + 点击文件可在应用内预览。 | 支持带空格和中文的路径、工作目录相对路径、文件链接和常见行号后缀。网络共享路径不在支持范围。应用内文本预览上限为 1 MB，图片为 5 MB。 |
| Codex 历史 | 打开已停止的默认账号任务，在主窗口按时间阅读对话，向上加载较早消息，再继续同一线程。标准新任务保存原生线程标识，旧任务可手动关联。 | 绑定依据是线程标识。同目录多个任务各自保留身份。复杂历史格式的覆盖仍有限。 |
| Codex 会话体积 | 查看已绑定会话的估算数据量、活动图片数和压缩次数。达到 2.5 MB 或 6 张图片时提示，达到 3.6 MB 或 10 张时提高提示级别。 | 压缩事件会重置活动数据计数。点击提示可复制 `/compact`，由用户决定是否执行。 |
| Kimi | 从项目启动 Kimi Code，读取支持的默认账号 wire 历史，通过原生恢复入口继续已有会话。 | 需要本地安装对应工具并有可识别的会话记录。 |
| Antigravity 命令行 | 读取受支持的本地会话标题和消息，在阅读器中查看历史，通过 `agy --conversation <id>` 恢复选定会话。也可识别有工作区关联的桌面记录。 | 只读访问历史，长消息可能截断并标记。桌面记录可读与桌面应用自动打开指定项目是两项独立能力。 |
| Antigravity 桌面入口 | 检测 Windows 安装，复制项目路径并打开桌面应用，然后在应用中选择项目。 | 桌面启动可独立于命令行工具使用。 |
| 工具、账号与额度 | 重新检测已安装工具，添加带参数的自定义启动命令。Codex、Claude Code、Kimi Code 可配置独立账号目录，按任务选择账号。顶部显示适配器能取得的模型或额度信息。 | 自定义命令只有通用终端能力。Claude Code 非默认账号无法从共享快照区分额度。Kimi 登录状态基于本地凭据文件是否存在。 |
| 工作台辅助 | 在项目面板查看提示词、文件、历史及工具连接情况；用量面板按本地记录汇总本周活动，提供 26 周热力图。 | 统计范围取决于工具记录的格式与可用字段。 |
| 窗口与个人设置 | 默认最大化启动。显示器拔出或布局改变时可将离屏窗口移回可见区域。支持中英文、首次启动引导、浅色／深色／随系统配色及编辑器主题。 | 休息提醒默认关闭，可手动开启、设置 1 至 12 小时间隔和语音提示。音乐播放器已在本版移除。 |

## 仍未实现或覆盖不完整

| 项目 | 当前缺口 |
| --- | --- |
| Codex 复杂历史 | 阅读器已有向上分页。原生历史存储中的分段、压缩、分支、回退及归档格式仍缺完整解析与恢复覆盖。识别压缩事件用于计数，并不足以重建压缩前对话。 |
| Antigravity 桌面自动定位 | 当前流程需要用户在桌面应用中选项目。直接打开指定项目或指定桌面会话仍缺经验证的启动协议。 |
| Antigravity 订阅额度 | 桌面安装、已登录、订阅权益、可用额度是不同状态。目前无法可靠地把桌面订阅映射为可用额度。 |
| 跨工具事件记录 | 全量原生事件接入、统一事件记录及更细的任务状态仍属后续方向。 |
| 多窗口工作台 | 当前主要流程在单个主窗口内切换项目和任务。多窗口属于后续候选，尚无交付日期。 |

## 从源码运行

OneTerm 是基于 [Qingxuan365/oneAI](https://github.com/Qingxuan365/oneAI/tree/f85e6b9162c66c421a526b51f3006863e6cd8c33) 开发的 Windows 桌面工作台。源码采用 [MIT License](LICENSE)，保留上游版权声明。公开版使用上游图标。

在 Windows x64 上安装 Node.js 20 和 npm 后，在仓库根目录运行：

~~~powershell
npm ci
npm run dev
~~~

~~~powershell
npm run build
npm run check:i18n
npm run check:workbench
npm run build:win
~~~

上述命令分别编译应用、检查界面翻译、运行工作台回归检查、生成 Windows 安装程序。安装程序输出到 release 目录。要使用 Codex、Kimi 或 Antigravity，请先安装相应工具。
